# NBA Three-Point Attempts — Time Series Analysis

Modeling and forecasting the evolution of three-point attempts in NBA games (1980–2023) using time series methods in R. Academic project in Applied Mathematics — ENSTA Paris / IP Paris (2026).

**Authors:** Leto Van Ruymbeke · Laura Sanchez

---

## Overview

Since the introduction of the three-point line in 1979, and especially after the 2009–2010 season (Stephen Curry's rookie year), three-point attempts have risen dramatically in the NBA. This project builds a complete time series model to capture this trend, decompose the signal, and forecast future values.

The final model combines a **GAM trend** (capturing long-run evolution) with an **ARMA(8,1) process** on the residuals (capturing autocorrelation structure), achieving a mean absolute error of **1.45 three-point attempts per game day** when predicting the entire 2023–2024 season.

---

## Methods

### 1. Data Preprocessing
- Raw data filtered from 1980-02-03 (corrupted records before that date)
- All-Star games excluded
- Multiple games per day aggregated to a daily mean (`mean_3pa`)

### 2. Trend Estimation
- **Rolling averages** (180-day, 365-day, 5-year windows) — limited by boundary effects and over-sensitivity to inter-season variation
- **GAM (Generalized Additive Model)** with spline smoothing
- Optimal `k` selected via **block cross-validation** (10 blocks of ~4 NBA seasons each), since GCV alone favors overfitting due to strong day-to-day autocorrelation
- Final model includes a dedicated **bump regressor** for the 1994–1997 period (temporary rule change shortening the three-point line)

### 3. Residual Modeling
- ACF/PACF analysis on GAM residuals to identify ARMA order
- **ARMA(8,1)** selected via AIC over all (p,q) with p,q ≤ 8
- Coefficients tested for significance with `coeftest` (lmtest): φ₄ and φ₇ constrained to 0
- Model validated with **Box-Pierce test** (p-value = 0.21 > 0.05) and residual diagnostics

### 4. Forecasting
- Out-of-sample prediction on the **2023–2024 NBA season** using `hoopR` for ground truth
- GAM extrapolation + ARMA `n.ahead` forecast combined
- **MAE = 1.45** / **RMSE** evaluated on the full season

---

## Results

| Step | Method | Outcome |
|---|---|---|
| Trend | GAM (k=11) + bump 1994–97 | Smooth long-run fit |
| Residuals | ARMA(8,1) constrained | Box-Pierce p = 0.21 ✓ |
| Forecast (2023–24) | GAM + ARMA | MAE = 1.45 attempts/day |

The model captures ~96% accuracy relative to current average three-point volume (~40 attempts per team per game), with residuals behaving as white noise.
